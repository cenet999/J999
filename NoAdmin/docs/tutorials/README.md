## 怎么看这套教程

- 想做列表页，先看 `NovaAdminTable`
- 想做选择器，先看 `NovaInputTable` 和 `NovaSelectTable`
- 想做权限分配，先看 `NovaAllocTable`
- 想做按钮权限控制，先看 `NovaButtonAttribute`
- 想做文件选择，先看 `NovaInputFile`
- 想做操作反馈，先看 `Toast`、`Message`、`Confirm`
