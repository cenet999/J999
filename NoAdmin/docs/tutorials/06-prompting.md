# 第六篇：提示类组件怎么用

NovaAdmin 里常见的提示，主要有三种：

- `Toast`：短提示，适合“成功了”“失败了”这种消息
- `Message`：页面内提示，适合业务通知和错误说明
- `Confirm`：确认框，适合删除、提交前再问一次

## `Toast`

`Toast` 适合做短时间提示。

常见写法：

- 成功：`Success`
- 失败：`Error`
- 警告：`Warning`

适合场景：

- 保存成功
- 上传成功
- 任务完成

## `Message`

`Message` 更像页面里的业务提示。

常见场景：

- 校验没通过
- 没有权限
- 业务规则不允许

## `Confirm`

`Confirm` 是让用户“先确认，再执行”。

适合场景：

- 删除数据
- 批量操作
- 不可恢复的操作

## 三者怎么记

- `Toast`：告诉你结果
- `Message`：告诉你问题
- `Confirm`：问你要不要继续

## 一句话建议

一般按这个顺序来：

1. 先校验
2. 校验失败用 `Message`
3. 需要确认用 `Confirm`
4. 成功后用 `Toast`
